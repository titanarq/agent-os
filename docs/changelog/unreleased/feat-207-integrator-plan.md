- `agent-os-integrate plan --prs N N N [--format summary|json]` (#207, `agent_os/product/integrator/`): the dry run of an integrator round. Read-only (`gh pr view`, `git fetch`): it drops what is not a candidate with a reason each (draft, wrong base, not mergeable, checks not all green, no approval on the current head, any unreadable fact), keeps solo what matches `integrator.solo_paths` or the built-in solo list, changes the test manifest or has a `full` own plan, and groups the rest greedily, oldest first, by same base, disjoint paths (renames count as both) and disjoint node `touches`, up to `integrator.max_group_size`. It prints the group, each solo pull request with its reason, and the union plan beside the largest member's. `changed_paths` and `merge_base_with_head` take an optional head reference (default `HEAD`).
