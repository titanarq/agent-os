- `agent-os-integrate build --prs N N N [--dry-run]` (#208, `agent_os/product/integrator/`): steps 1-4 of the integrator. Under a non-blocking `flock` on `.cache/integrator.lock` (one integration in flight) it fetches, records `base = origin/main`, makes a throwaway worktree at base and merges each member's pinned head with `--no-ff` in number order; a conflicting merge is aborted and that pull request leaves the group (solo, reason printed), never resolved. On the integrated tree it runs `ruff check`, `ruff format --check`, `python -m agent_os.quality --base <base>` and `agent-os-tests check` (no tests); a failure names the paths and the members that contribute them, exit 1, nothing pushed, lock released. Otherwise it pushes `integration/<UTC stamp>`, opens the pull request `integration: #A #B` (body: each member and its pinned head, no `Closes`) and prints one line: its number, the base and the members. `--dry-run` prints the commands and changes nothing.
