- `agent-os-tree in-works [--root DIR] [--json]` (#218) -- a read-only command that prints, per tree node with something open, its open issues (`<!-- node: <id> -->`, with the `project.labels` state label they hold) and the open pull requests that close one of them (`Closes #N`) or change `<tree.root>/<id>.md`. A node with nothing open is absent; a `gh` failure exits 1 with the reason and never prints an empty map. Repository, labels and tree root come from `config/agents.yaml`; the host decides what to show (`agent_os/product/board/in_works/`).
