- `agent-os-integrate result <integration PR> [--summary-index suite.summary.json]` (#209, `agent_os/product/integrator/result/`): waits at most `integrator.ci_wait_max_minutes` for the integration head's checks with `bin/dev/wait_checks.sh` and prints one verdict. `passed` when every check is SUCCESS; `solo: <why>` for a timeout, an infrastructure red (a conclusion other than FAILURE), a red with no summary index, a failing test no member's own test plan selects, or several members implicated; `evict #N` when the failing tests of the index (never the raw log) are all selected by the plan of exactly one member. `agent-os-integrate build --prs ... --without N` rebuilds once without the evicted member and records it in the integration pull request's body; a second failure of that rebuilt group is `solo`. No bisection.
