- `agent-os-integrate land <integration PR>` lands a passed group: each member merges natively, in number order, with `project.merge_method`, through `bin/dev/safe_merge.sh <repo> <pr> --group <integration PR>`; then `tree(origin/main)` is compared with the integration head's (a difference stops the rest and pages `notify.sh`), and the integration pull request is closed without merging, with a comment listing what landed, and its branch deleted. `--group` replaces "head does not contain origin/main" by three checks (integration head green and holding the pinned head, `origin/main` still the base or the previous member's merge commit via `--after`, member head equal to the pinned one); without it `safe_merge.sh` is unchanged.
