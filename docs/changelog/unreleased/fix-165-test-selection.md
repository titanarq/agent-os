- `agent-os-tests check|plan|run` (#165) -- the selection half of per-branch testing: a manifest named by `project.test_selection.manifest` (a file, or a folder of `*.yaml`; empty keeps selection off) maps tests to groups, and `plan` prints the tests a branch must run from the three-dot diff (groups by `covers`/`tests`/tree `nodes`, integration tests with a selected side, `always`; any change nobody covers is the whole suite), `check` fails an unmapped test file, and `run` execs `project.test_command` with the selected paths. Also `python -m agent_os.product.test_selection`.
